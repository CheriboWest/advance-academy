# The sponsor-register resolver (app/sponsors/resolver.py) calls
# messages.create(..., output_config=...) for structured JSON output.
# `output_config` replaced the earlier `output_format` parameter in 0.77.0 and
# has been stable since; anthropic>=0.69 (the previous floor here) allowed pip
# to resolve versions as old as 0.69.0, which predate it entirely and raise
# `TypeError: Messages.create() got an unexpected keyword argument
# 'output_config'` — a local error, before any request reaches the network.
# 0.125.0 is the version this resolver was built and tested against; pinned as
# the floor so a stale build cache or an unpinned resolution elsewhere can't
# silently reintroduce the same failure. Kept below 1.0: that major version
# changes the HTTP client (httpx2) and removes deprecated parameters, and
# migrating to it is a separate, deliberate upgrade, not a compatibility fix.
